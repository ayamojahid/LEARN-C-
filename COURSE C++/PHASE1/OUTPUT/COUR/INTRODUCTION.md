# 🟦 Introduction à C++

## 1. C’est quoi C++ ?

**C++ est un langage de programmation.**

Il permet au programmeur de donner des **instructions à l’ordinateur** pour créer des programmes.

On peut utiliser C++ pour créer :

* 🖥️ Logiciels
* 🎮 Jeux vidéo
* ⚙️ Systèmes et programmes performants
* 🤖 Systèmes embarqués
* 📊 Applications utilisant des algorithmes complexes

---

## 2. Pourquoi apprendre C++ ?

C++ permet de construire une **bonne base en programmation**.

On apprend notamment :

* **Variables** → stocker des données
* **Types de données** → `int`, `float`, `char`, etc.
* **Opérateurs** → faire des calculs et des comparaisons
* **Conditions** → prendre des décisions
* **Boucles** → répéter des instructions
* **Fonctions** → réutiliser et organiser le code
* **Tableaux** → stocker plusieurs valeurs
* **Structures** → regrouper plusieurs données
* **Mémoire** → comprendre comment les données sont stockées
* **Algorithmes** → résoudre des problèmes

👉 C++ aide donc à comprendre **comment programmer et comment fonctionne un programme**.

---

## 3. C++ et la POO

**POO = Programmation Orientée Objet**
En anglais : **OOP = Object-Oriented Programming**

La POO est une façon d'organiser un programme autour d'**objets**.

### Exemple : une voiture 🚗

Une voiture possède des **attributs** :

```text
marque = Toyota
couleur = rouge
vitesse = 100
```

Elle possède aussi des **méthodes** :

```text
demarrer()
accelerer()
freiner()
```

### Classe et objet

**Classe = modèle**

**Objet = élément créé à partir du modèle**

```text
Classe Voiture
      ↓
    modèle
      ↓
Objet Voiture
```

La POO permet de créer des programmes **mieux organisés et réutilisables**.

---

## 4. C++ est multiplateforme

C++ peut être utilisé sur plusieurs systèmes d'exploitation :

* 🪟 **Windows**
* 🍎 **macOS**
* 🐧 **Linux**

Le langage C++ reste le même, mais les outils de développement peuvent être différents.

---

## 5. C++ est un langage compilé

C++ est généralement **compilé**.

Le programmeur écrit du code C++ :

```text
Code C++
   ↓
Compilateur
   ↓
Programme exécutable
   ↓
Ordinateur
```

### Compilateur

Un **compilateur** est un programme qui transforme le **code source C++** en un programme que l'ordinateur peut exécuter.

---

## 6. C++ et la logique

Le plus important n'est pas de mémoriser la syntaxe.

Il faut apprendre à suivre cette logique :

**Problème → Réflexion → Algorithme → Code C++ → Résultat**

Par exemple :

```text
Problème :
Calculer la somme de deux nombres

      ↓

Algorithme :
1. Lire A
2. Lire B
3. Calculer A + B
4. Afficher le résultat

      ↓

Programme C++
```

🧠 Mémoire → contrôle précis de la mémoire

## 🟦 C++ — Main Advantages

### ⚡ Performance

C++ permet de créer des programmes qui utilisent efficacement les ressources de l'ordinateur, comme le **CPU et la mémoire**.

### 🚀 Speed

C++ est connu pour sa **rapidité d'exécution**. Le code C++ est généralement **compilé** avant d'être exécuté.

**C++ code → Compiler → Machine code → Execution**

### 🌍 Cross-Platform / Adaptable

C++ peut être utilisé sur plusieurs systèmes :

* **Windows**
* **macOS**
* **Linux**

Un même programme peut souvent être adapté à plusieurs plateformes.

### 🧮 High-Level Mathematical Computations

C++ peut effectuer des **calculs mathématiques complexes et intensifs**, par exemple dans :

* les simulations ;
* les calculs scientifiques ;
* l'ingénierie ;
* les applications nécessitant beaucoup de calculs.

### 🧵 Multithreading with Concurrency

C++ permet d'utiliser plusieurs **threads** pour gérer plusieurs tâches de manière concurrente.

Exemple :

```text
             Programme
                 |
       ┌─────────┼─────────┐
       ↓         ↓         ↓
    Thread 1  Thread 2  Thread 3
    Calcul    Download   Interface
```

Cela peut permettre de mieux utiliser les **plusieurs cœurs du processeur**.

### ⭐ À retenir

**C++ → Performance + Speed + Cross-platform + Complex computations + Multithreading/Concurrency**
